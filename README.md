# After Hours Gothic

An original Gothic x cyberpunk display type system, cut from one skeleton in two styles:
**Display** (hero) and **Heading** (website headings, small sizes).

## Download

- Display: https://filebin.net/afterhoursgothic/AfterHoursGothic-Display.otf
- Heading: https://filebin.net/afterhoursgothic/AfterHoursGothic-Heading.otf
- Concept sheet: https://filebin.net/afterhoursgothic/after-hours-gothic-concept-sheet.png

Both are working OpenType (CFF) fonts, 1000 units per em.

## Character support

A-Z, a-z, 0-9 and . , : ; ! ? ' " smart quotes, dashes, / \ ( ) + = * # @ & middot times degree, space.
88 mapped characters in each style. No accents, no non-Latin scripts.

## The six rules

1. Contrast axis: verticals 138 units, horizontals 34.
2. Cathedral aperture: every bowl is a faceted arch with a pointed apex; no true curves.
3. Shear terminal: every open stroke ends on a 17 degree shear.
4. The break: every closed counter is cut once at four o'clock.
5. Inline trace (Display only): an 18-unit slit down every vertical carrier.
6. Two currents: Display 138:34 with trace and spike; Heading 150:86, flat cuts, +10 tracking.
