# After Hours Gothic

An original Gothic x cyberpunk display type system: one skeleton, two styles.
**Display** for hero headlines, **Heading** for website headings and small sizes.

## Download
- [AfterHoursGothic-Display.otf](AfterHoursGothic-Display.otf) - Display, hero
- [AfterHoursGothic-Heading.otf](AfterHoursGothic-Heading.otf) - Heading, quiet
- [Concept sheet](after-hours-gothic-concept-sheet.png) and [hero still](hero-16x9.png)

Working OpenType (CFF) fonts, 1000 units per em, 91 mapped characters each; installable on macOS, Windows, Linux, iOS and Android.

## The six rules
1. Contrast axis: verticals 138 units, horizontals 34.
2. Cathedral aperture: faceted arch bowls, pointed apex, no true curves.
3. Shear terminal: every open stroke ends on a 17 degree shear.
4. The break: every closed counter is cut once at four o'clock.
5. Inline trace (Display only): an 18-unit slit down each vertical carrier.
6. Two currents: Display 138:34 with trace and spike; Heading 150:86, flat cuts, +10 tracking.

## Design notes
Gothic bones - pointed arches, hard contrast, sharp terminals - cut open with a sheared edge on every stroke end, one circuit break in every closed counter, and a neon inline trace in Display. One skeleton at two voltages, so a headline and the body copy under it come from the same night.

Original work, not traced from any existing typeface. CC BY 4.0.
